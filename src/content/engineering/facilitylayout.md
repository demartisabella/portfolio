## Project Overview

This project optimized the production layout of a manufacturing facility to improve material flow, reduce unnecessary transportation, and increase production capacity.

## Problem

The existing layout generated excessive movement, inefficient workstation interactions, and poor utilization of the available production area.

## Engineering Approach

The redesign followed Systematic Layout Planning (SLP) principles supported by process analysis and flow evaluation.

The project included:

- Material flow analysis
- Relationship diagrams
- Space requirement calculations
- Alternative layout generation
- Capacity evaluation


## Key Results

- 20% capacity increase (960 → 1,152 trays per cycle)
- Space utilization improvement: 43.59% → 52.31% (8.72 percentage points)
- Identified 16 additional tables without civil works
- Created formal technical layout documentation for the first time
- Established process-sequenced area organization
- Financial analysis showed positive NPV of ₡243,082.95 with 10% TMAR

## Impact

This redesign eliminated a 20% capacity opportunity cost without requiring any new infrastructure investment. By implementing logical process sequencing, the project reduced unnecessary movement and cross-flow between production stages, directly improving operational efficiency. This optimization not only provided a technical foundation for future expansion decisions but also immediately enhanced the company's ability to accept larger orders and onboard new clients.

## Lessons Learned

Applying SLP proved that systematic layout planning is highly effective for agricultural facilities, not just traditional manufacturing. I learned that strategic space optimization can yield significant capacity gains without capital expenditure, provided that process sequence—not mere convenience—drives the physical arrangement. Furthermore, pairing formal layout documentation with financial validation is essential to strengthen any operational improvement proposal.
